# 题型格式模板

五类题型标准格式（严格按照此模板输出，确保可被考试系统导入）。

## 1. 单选题
```
【单选题】题干（答案字母）
选项A
选项B
选项C
选项D
解析：……（解析文字必须与所标答案一致）
难易度：低/中/高
分数：2
```
示例：
```
【单选题】世界上第一台电子数字计算机取名为（C）
UNIVAC
EDSAC
ENIAC
EDVAC
解析：第一台计算机名为ENIAC
难易度：低
分数：2
```

## 2. 多选题
```
【多选题】题干（答案字母组合，如BEFG）
选项A
选项B
……
解析：……
难易度：低/中/高
分数：1
```
示例：
```
【多选题】下列数据中属于输入设备的是（BEFG）
显示器
键盘
打印机
绘图仪
鼠标
扫描仪
激光笔
解析：输入设备包括键盘、鼠标、扫描仪、激光笔等
难易度：低
分数：1
```

## 3. 判断题
```
【判断题】题干（正确/错误）
解析：……
难易度：低/中/高
分数：1
```
示例：
```
【判断题】通过FTP可以上载网页（正确）
解析：FTP可用于文件上载
难易度：低
分数：1
```

## 4. 填空题
```
【填空题】题干，空白处用___表示
填空1：正确答案|可接受备选
填空2：正确答案
解析：……
难易度：低/中/高
分数：2
考核点：知识点A | 知识点B
```
示例：
```
【填空题】TCP/IP协议参考模型，由网络接口层、网际层、___、___组成
填空1：传输层|传输
填空2：应用层
解析：TCP/IP协议参考模型，由网络接口层、网际层、传输层、应用层组成
难易度：低
分数：2
考核点：TCP协议 | IP协议
```

## 5. 简答题
```
【简答题】题干。
正确答案：……（完整答案要点）
难易度：低/中/高
分数：1（或按分值）
```
示例：
```
【简答题】请简述网络三次握手原理。
正确答案：所谓"三次握手"是为对每次发送数据量进行跟踪与协商，确保数据段发送和接收同步……
难易度：低
分数：1
```

## 格式约束（必守）
- 题干末尾括号内标注答案：单选/多选为字母，判断为"正确/错误"
- 解析文字必须与所标答案指向的选项一致，不得自相矛盾
- 选项逐行排列，无编号前缀（A/B/C 由行序自动对应）
- 每题区块以空行分隔；模块可用 `========== 模块名 题数 ==========` 分隔
