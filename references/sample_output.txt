# 完整输出样例（黄金标准）

**这是唯一正确的输出格式。出题时必须严格参照此样例，逐字对齐结构。**

---

```
纵腾集团新人培训考试题库（示例：前 18 题）

========== 一、集团简介（12题）==========

【单选题】纵腾集团的企业定位是（A）
全球跨境电商基础设施服务商
国内电商物流服务商
跨境支付平台
海外仓储服务商
解析：纵腾集团以"全球跨境电商基础设施服务商"为企业定位，聚焦跨境仓储与物流。
难易度：低
分数：2

【单选题】纵腾集团正式创办于哪一年（B）
2006年
2009年
2014年
2018年
解析：2006年从事跨境电子商务行业，2009年正式创办福建纵腾网络有限公司。
难易度：低
分数：2

【多选题】纵腾集团旗下拥有哪些知名品牌（ABCD）
谷仓海外仓
云途物流
京东物流
顺丰速运
菜鸟网络
解析：纵腾集团旗下拥有谷仓海外仓、云途物流等知名品牌。
难易度：低
分数：2

【判断题】纵腾集团的总部位于深圳（错误）
解析：纵腾集团公司地址位于福州市鼓楼区软件园。
难易度：低
分数：1

【填空题】纵腾集团成立于___年，总部位于___市
填空1：2009|2009年
填空2：福州
解析：2009年正式创办福建纵腾网络有限公司，公司地址位于福州市鼓楼区软件园。
难易度：低
分数：2
考核点：成立年份 | 总部城市

【简答题】请简述纵腾集团的四大业务板块。
正确答案：纵腾集团四大业务板块包括：（1）谷仓海外仓——海外仓储服务；（2）云途物流——跨境物流服务；（3）沃德太客——跨境分销服务；（4）其他增值服务。
难易度：中
分数：5

========== 二、企业文化（6题）==========

【单选题】纵腾集团的使命是什么（C）
让跨境更简单
成为全球领先的跨境电商基础设施服务商
成就客户 协作共赢 追求卓越 诚信正直
以上都不是
解析：纵腾集团的使命是"成就客户 协作共赢 追求卓越 诚信正直"，愿景是"让跨境更简单"。
难易度：低
分数：2
```

## 格式要点对照表（每题必须包含以下要素）

| 要素 | 位置 | 示例 | 必须遵守 |
|------|------|------|----------|
| 题型标记 | 每题第一行开头 | `【单选题】` | 用中文方括号 |
| 题干 | 题型标记后 | `纵腾集团的企业定位是` | 以问句或陈述句结尾 |
| 答案 | 题干末尾括号内 | `（A）` / `（ABCD）` / `（正确）` | 单选=单字母，多选=字母组合，判断=正确/错误 |
| 选项 | 题干下方逐行 | 第1行=A, 第2行=B... | **无编号前缀**，由行序自动对应 |
| 解析 | 选项下方 | `解析：……` | 必须与所标答案一致 |
| 难易度 | 解析下方 | `难易度：低` | 低/中/高 三选一 |
| 分数 | 难易度下方 | `分数：2` | 数字 |
| 分隔 | 每题之间 | 空行 | 一行空行 |

## ⛔ 绝对禁止的格式（常见错误）

### 错误格式 A：试卷式（答案速查 + 解析分离）
```
❌ 参考答案与解析
❌ 一、答案速查
❌ 1.B  2.A  3.C ...
❌
❌ 一、集团简介 — 解析
❌ 1. 答案：B  解析：……
```
**原因**：这不是题库文件，无法被考试系统导入，也无法被 consistency_check.py 校验。

### 错误格式 B：选项带编号前缀
```
❌ A. 全球跨境电商基础设施服务商
❌ B. 国内电商物流服务商
```
**原因**：模板规定选项无编号前缀，行序即对应 A/B/C/D。

### 错误格式 C：缺少解析/难易度/分数
```
❌ 【单选题】纵腾集团的企业定位是（A）
❌ 全球跨境电商基础设施服务商
❌ （没有解析、难易度、分数）
```
**原因**：每题必须完整包含全部 6 个要素。
