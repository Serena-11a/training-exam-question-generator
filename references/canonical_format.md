# 标准试题格式（权威规范）

> ⚠️ 本文件是出题格式的**唯一权威标准**。生成任何题目之前，必须先向用户展示本格式并确认「是否按此格式出题」，未确认不得开工。

## 🔴 最高优先级规则（违反即不合格）

1. **每题之间必须有空行分隔** —— 绝对不允许题目连在一起形成文字墙。
2. **答案置于题干后中文圆括号内**：单选/多选为字母（`C` / `BEFG`）；判断为 `正确`/`错误`。
3. **选项不要带 A./B./C./D. 序号前缀** —— 直接写选项文字，每个选项单独一行。

---

## 五类题型标准格式

### 1. 单选题
第一行：题型 + 题干（答案字母在括号内）；随后每个选项单独一行（无前缀）；再 解析 一行、难易度 一行；结束。
```
【单选题】世界上第一台电子数字计算机取名为（C）
UNIVAC
EDSAC
ENIAC
EDVAC
解析：第一台电子数字计算机名为ENIAC
难易度：低
```

### 2. 多选题
与单选同理，答案可为多字母；每个选项单独一行（无前缀）。
```
【多选题】下列数据中属于输入设备的是（BEFG）
显示器
键盘
打印机
绘图仪
鼠标
扫描仪
激光笔
解析：键盘、鼠标、扫描仪、激光笔属于输入设备
难易度：低
```

### 3. 判断题
无选项行，第一行题干后直接接 解析、难易度。
```
【判断题】通过FTP可以上载网页（正确）
解析：FTP支持文件上传（上载）功能
难易度：低
```

### 4. 填空题（特殊：填空项在题干同行，含 分数 与 考核点）
第一行：题型 + 题干（含 `___` 空位）+ `填空N：答案|备选` 置于**同行**；随后 解析、难易度、分数、考核点 各占一行。
```
【填空题】TCP/IP协议参考模型，由网络接口层、网际层、___、___组成 填空1：传输层|传输 填空2：应用层
解析：TCP/IP协议参考模型，由网络接口层、网际层、传输层、应用层组成
难易度：低
分数：2
考核点：TCP协议 | IP协议
```

### 5. 简答题
第一行题型 + 题干；随后 解析（含答案要点）一行、难易度 一行；结束（无分数、无考核点）。
```
【简答题】请简述网络三次握手原理。
解析：三次握手用于在通信前确认双方收发能力并建立可靠连接：第一次客户端发送SYN；第二次服务端回SYN+ACK；第三次客户端回ACK，连接建立。
难易度：低
```

## 完整多题输出示例（⭐ 请严格照此排版）

注意**每题之间的空行**，以及「第一行题目 → 选项逐行（无前缀）→ 解析一行 → 难易度一行 → 结束」的结构（填空题额外含 填空N 同行 + 分数 + 考核点）：

```
【单选题】世界上第一台电子数字计算机取名为（C）
UNIVAC
EDSAC
ENIAC
EDVAC
解析：第一台电子数字计算机名为ENIAC
难易度：低

【多选题】下列数据中属于输入设备的是（BEFG）
显示器
键盘
打印机
绘图仪
鼠标
扫描仪
激光笔
解析：键盘、鼠标、扫描仪、激光笔属于输入设备
难易度：低

【判断题】通过FTP可以上载网页（正确）
解析：FTP支持文件上传（上载）功能
难易度：低

【填空题】TCP/IP协议参考模型，由网络接口层、网际层、___、___组成 填空1：传输层|传输 填空2：应用层
解析：TCP/IP协议参考模型，由网络接口层、网际层、传输层、应用层组成
难易度：低
分数：2
考核点：TCP协议 | IP协议

【简答题】请简述纵腾集团的企业定位。
解析：纵腾集团以"全球跨境电商基础设施服务商"为企业定位，致力于为跨境电商提供海外仓、专线物流、供应链等基础设施服务。
难易度：低

【单选题】纵腾集团成立于哪一年（C）
2005年
2006年
2007年
2008年
解析：纵腾集团成立于2007年
难易度：低
```

## 出题前确认闸门（必守）
生成题目之前，必须先把以上格式展示给用户，并明确询问：

> 「接下来出的题，是否都采用以下格式？
> - 单选/多选/判断/填空/简答 五类
> - **第一行**：题型 + 题干（答案置于题干后括号内，如（C）/（BEFG）/（正确））
> - **每个选项单独一行，不带 A./B./C. 序号前缀**，直接写选项文字
> - **解析 单独一行、难易度 单独一行**；填空题额外在题干同行写 `填空N：答案|备选`，并带 分数、考核点 行
> - **每题之间有空行分隔**（不连成文字墙）
> □ 是，按这个格式出　　□ 否，我用自己的格式（附样本）」

待用户明确回复确认（如「确认」「按这个来」「可以出题」）后，方可进入出题步骤。任何一项未确认，必须停下等待。

---

## 禁止格式（出现即不合格）
- ❌ 选项带 `A.` `B.` `C.` `D.` 序号前缀
- ❌ 所有选项挤在同一行（如 `A.UNIVAC B.EDSAC ...`）
- ❌ 所有题连在一起无空行（文字墙）
- ❌ 填空题写成「填空答案只在解析行」——必须 `填空N：答案|备选` 置于题干同行，且带 分数、考核点
- ❌ 试卷式排版（答案速查表 + 解析分离）
