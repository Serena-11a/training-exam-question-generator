# 标准试题格式（权威规范）

> ⚠️ 本文件是出题格式的**唯一权威标准**。生成任何题目之前，必须先向用户展示本格式并确认「是否按此格式出题」，未确认不得开工。

## 🔴 最高优先级规则（违反即不合格）

### 规则 1：每题之间必须有空行分隔
每道题输出完后，必须插入一个**空行（空白换行）**再开始下一道题。绝对不允许题目连在一起形成文字墙。

### 规则 2：题目首行 + 选项逐行 + 字段逐行（到此结束）
一道题结构如下（以多选题为例）：
```
【多选题】下列哪些属于企业文化的三要素（ABC）
A. 尊重
B. 务实
C. 卓越
D. 共赢
解析：纵腾集团企业文化三要素为尊重、务实、卓越（此处为示例说明）
难易度：低
```
- **第一行**：题型标记 + 题干，答案置于题干后中文圆括号内（单选/多选为字母 `C` / `BEFG`；判断为 `正确`/`错误`）
- **随后每个选项单独一行**：用 `A.` `B.` `C.` `D.` 编号，与答案字母对应
- **解析 单独一行**：`解析：……`
- **难易度 单独一行**：`难易度：低/中/高`
- **到此结束** —— 不输出分数、不输出考核点、不输出其他任何字段

### 规则 3：每题自含
- 禁止「答案速查表 + 解析分离」的试卷式排版
- 填空题、简答题的答案写入「解析」行（因本格式不单独设答案字段，用「答案：」标注）

## 五类题型逐题样例

### 1. 单选题
```
【单选题】世界上第一台电子数字计算机取名为（C）
A. UNIVAC
B. EDSAC
C. ENIAC
D. EDVAC
解析：第一台电子数字计算机名为ENIAC
难易度：低
```

### 2. 多选题
```
【多选题】下列数据中属于输入设备的是（BEFG）
A. 显示器
B. 键盘
C. 打印机
D. 绘图仪
E. 鼠标
F. 扫描仪
G. 激光笔
解析：键盘、鼠标、扫描仪、激光笔属于输入设备
难易度：低
```

### 3. 判断题
```
【判断题】通过FTP可以上载网页（正确）
解析：FTP支持文件上传（上载）功能
难易度：低
```
（判断题无 A./B. 选项行，第一行题干后直接接解析）

### 4. 填空题
```
【填空题】纵腾集团成立于___年，总部位于___
解析：纵腾集团成立于2007年，总部位于深圳（答案：2007、深圳）
难易度：低
```
（填空答案写入解析行，用「答案：」标注；不单独设填空N行、不设考核点）

### 5. 简答题
```
【简答题】请简述纵腾集团的企业使命。
解析：纵腾集团以"全球跨境电商基础设施服务商"为企业定位，致力于……（此处填入完整答案要点）
难易度：低
```
（简答题答案写入解析行；不单独设正确答案行、不设考核点）

## 完整多题输出示例（⭐ 请严格照此排版）

注意**每题之间的空行**，以及「第一行题目 → 选项逐行 → 解析一行 → 难易度一行 → 结束」的结构：

```
【单选题】世界上第一台电子数字计算机取名为（C）
A. UNIVAC
B. EDSAC
C. ENIAC
D. EDVAC
解析：第一台电子数字计算机名为ENIAC
难易度：低

【多选题】下列数据中属于输入设备的是（BEFG）
A. 显示器
B. 键盘
C. 打印机
D. 绘图仪
E. 鼠标
F. 扫描仪
G. 激光笔
解析：键盘、鼠标、扫描仪、激光笔属于输入设备
难易度：低

【判断题】通过FTP可以上载网页（正确）
解析：FTP支持文件上传（上载）功能
难易度：低

【填空题】纵腾集团成立于___年
解析：纵腾集团成立于2007年（答案：2007）
难易度：低

【简答题】请简述纵腾集团的企业使命。
解析：纵腾集团以"全球跨境电商基础设施服务商"为定位，使命是……（答案要点）
难易度：低

【单选题】HTTP协议默认端口号是（A）
A. 80
B. 443
C. 8080
D. 3306
解析：HTTP协议默认使用80端口
难易度：低
```

## 出题前确认闸门（必守）
生成题目之前，必须先把以上格式展示给用户，并明确询问：

> 「接下来出的题，是否都采用以下格式？
> - 单选/多选/判断/填空/简答 五类
> - **第一行**：题型 + 题干（答案置于题干后括号内，如（C）/（BEFG）/（正确））
> - **每个选项单独一行**（A. B. C. D. 编号）
> - **解析 单独一行、难易度 单独一行**
> - **没有分数、没有考核点**，到此结束
> - **每题之间有空行分隔**（不连成文字墙）
> □ 是，按这个格式出　　□ 否，我用自己的格式（附样本）」

待用户明确回复确认（如「确认」「按这个来」「可以出题」）后，方可进入出题步骤。任何一项未确认，必须停下等待。
