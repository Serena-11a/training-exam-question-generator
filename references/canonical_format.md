# 标准试题格式（权威规范）

> ⚠️ 本文件是出题格式的**唯一权威标准**。生成任何题目之前，必须先向用户展示本格式并确认「是否按此格式出题」，未确认不得开工。

## 格式总览
- 题型标记：【单选题】【多选题】【判断题】【填空题】【简答题】
- 答案紧接题干，置于中文圆括号内：单选/多选为字母（如 `C` / `BEFG`），判断为「正确/错误」
- 选项以**空格分隔**，紧跟答案之后，写在同一行（不使用 A. B. C. 编号前缀）
- 每题末尾依次带：`解析` → `难易度` → `分数`；填空额外带「填空N」与「考核点」
- 全部自包含，禁止使用「答案速查表 + 解析分离」的试卷式排版

## 1. 单选题
```
【单选题】世界上第一台电子数字计算机取名为（C）UNIVAC EDSAC ENIAC EDVAC 解析：第一台计算机名为ENIAC 难易度：低 分数：2
```
格式：`【单选题】题干（答案字母）选项1 选项2 选项3 选项4 解析：…… 难易度：低/中/高 分数：N`

## 2. 多选题
```
【多选题】下列数据中属于输入设备的是（BEFG）显示器 键盘 打印机 绘图仪 鼠标 扫描仪 激光笔 难易度：低 分数：1
```
格式：`【多选题】题干（答案字母组合）选项1 选项2 … 解析：…… 难易度：低/中/高 分数：N`

## 3. 判断题
```
【判断题】通过FTP可以上载网页（正确）难易度：低 分数：1
```
格式：`【判断题】题干（正确/错误）难易度：低/中/高 分数：N`

## 4. 填空题
```
【填空题】TCP/IP协议参考模型，由网络接口层、网际层、___、___组成 填空1：传输层|传输 填空2：应用层 解析：TCP/IP协议参考模型，由网络接口层、网际层、传输层、应用层组成 难易度：低 分数：2 考核点：TCP协议 | IP协议
```
格式：`【填空题】题干（___ 表示空） 填空1：正确答案|备选 填空2：正确答案 解析：…… 难易度：低/中/高 分数：N 考核点：知识点A | 知识点B`

## 5. 简答题
```
【简答题】请简述网络三次握手原理。正确答案：所谓的"三次握手"：为了对每次发送的数据量进行跟踪与协商，确保数据段的发送和接收同步，根据所接收到的数据量而确认数据发送、接收完毕后何时撤消联系，并建立虚连接。为了提供可靠的传送，TCP在发送新的数据之前，以特定的顺序将数据包的序号，并需要这些包传送给目标机之后的确认消息。TCP总是用来发送大批量的数据。当应用程序在收到数据后要做出确认时也要用到TCP。 难易度：低 分数：1
```
格式：`【简答题】题干。正确答案：…… 难易度：低/中/高 分数：N`

## 出题前确认闸门（必守）
生成题目之前，必须先把以上格式展示给用户，并明确询问：

> 「接下来出的题，是否都采用以上格式（单选/多选/判断/填空/简答：答案置于括号内、选项空格分隔、末尾带解析+难易度+分数）？」

待用户明确回复确认（如「确认」「按这个来」「可以出题」）后，方可进入出题步骤。任何一项未确认，必须停下等待。
