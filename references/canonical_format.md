# 标准试题格式（权威规范）

> ⚠️ 本文件是出题格式的**唯一权威标准**。生成任何题目之前，必须先向用户展示本格式并确认「是否按此格式出题」，未确认不得开工。

## 🔴 最高优先级规则（违反即不合格）

### 规则 1：每题之间必须有空行分隔
每道题输出完后，必须插入一个**空行（空白换行）**再开始下一道题。绝对不允许题目连在一起形成文字墙。

### 规则 2：字段分行（题干单行 + 字段逐行）
- **第一行**：题型标记 + 题干(答案) + 选项，**全部在同一行**
- **随后每行一个字段**：`解析` / `难易度` / `分数` 各占一行（填空题另带 `填空N` 行与 `考核点` 行；简答题第二行为 `正确答案：……`）
- 一条题的结构：
  ```
  第1行：【题型】题干（答案）选项1 选项2 ……
  第2行：解析：……
  第3行：难易度：低/中/高
  第4行：分数：N
  ```

### 规则 3：每题自含
- 答案置于题干后中文圆括号内：单选/多选为字母（`C` / `BEFG`），判断为「正确/错误」
- 选项以**空格分隔**，紧跟答案之后（不使用 A. B. C. 编号前缀）
- 禁止「答案速查表 + 解析分离」的试卷式排版

## 五类题型逐题样例

### 1. 单选题
```
【单选题】世界上第一台电子数字计算机取名为（C）UNIVAC EDSAC ENIAC EDVAC
解析：第一台计算机名为ENIAC
难易度：低
分数：2
```
模板：
```
【单选题】题干（答案字母）选项1 选项2 选项3 选项4
解析：……
难易度：低/中/高
分数：N
```

### 2. 多选题
```
【多选题】下列数据中属于输入设备的是（BEFG）显示器 键盘 打印机 绘图仪 鼠标 扫描仪 激光笔
解析：键盘、鼠标、扫描仪、激光笔属于输入设备
难易度：低
分数：1
```
模板：
```
【多选题】题干（答案字母组合）选项1 选项2 ……
解析：……
难易度：低/中/高
分数：N
```

### 3. 判断题
```
【判断题】通过FTP可以上载网页（正确）
解析：FTP支持文件上传（上载）功能
难易度：低
分数：1
```
模板：
```
【判断题】题干（正确/错误）
解析：……
难易度：低/中/高
分数：N
```

### 4. 填空题
```
【填空题】TCP/IP协议参考模型，由网络接口层、网际层、___、___组成
填空1：传输层|传输
填空2：应用层
解析：TCP/IP协议参考模型，由网络接口层、网际层、传输层、应用层组成
难易度：低
分数：2
考核点：TCP协议 | IP协议
```
模板：
```
【填空题】题干（___ 表示空）
填空1：答案|备选
填空2：答案
解析：……
难易度：低/中/高
分数：N
考核点：知识点A | 知识点B
```

### 5. 简答题
```
【简答题】请简述网络三次握手原理。
正确答案：所谓的"三次握手"：为了对每次发送的数据量进行跟踪与协商，确保数据段的发送和接收同步，根据所接收到的数据量而确认数据发送、接收完毕后何时撤消联系，并建立虚连接。为了提供可靠的传送，TCP在发送新的数据之前，以特定的顺序将数据包的序号，并需要这些包传送给目标机之后的确认消息。TCP总是用来发送大批量的数据。当应用程序在收到数据后要做出确认时也要用到TCP。
难易度：低
分数：1
```
模板：
```
【简答题】题干。
正确答案：……
难易度：低/中/高
分数：N
```

## 出题前确认闸门（必守）
生成题目之前，必须先把以上格式展示给用户，并明确询问：

> 「接下来出的题，是否都采用以下格式？
> - 单选/多选/判断/填空/简答 五类
> - 题干与选项在同一行（答案括号内、选项空格分隔）
> - **解析 / 难易度 / 分数 各占一行**（填空另带 填空N、考核点）
> - **每题之间有空行分隔**（不连成文字墙）
> □ 是，按这个格式出　　□ 否，我用自己的格式（附样本）」

待用户明确回复确认（如「确认」「按这个来」「可以出题」）后，方可进入出题步骤。任何一项未确认，必须停下等待。
